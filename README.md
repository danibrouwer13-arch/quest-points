# Quest Points

Een simpele XP/quest-website.

## Bestanden
- `index.html` — website
- `style.css` — ontwerp
- `script.js` — taken, XP, random quests en opslag

## Lokaal openen
Open `index.html` in Chrome/Edge/Firefox.

## Online zetten
Je kunt deze drie bestanden uploaden naar een statische hostingdienst zoals GitHub Pages of Cloudflare Pages.

De XP en taken worden opgeslagen in de browser met `localStorage`. Dit betekent dat ze op hetzelfde apparaat en in dezelfde browser blijven staan.
